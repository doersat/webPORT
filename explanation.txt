ДЛЯ МОЕЙ ТЦПОЙ ГОЛОВЫ

@keyframes - команда говорящая браузеру звпоминать последоватльность изменений, чтобы потом была возможность применять 
к какому-либо другому элементу

spinAndFloat - название просто

gap - задает расстояние (промежуток) между элементами внутри flex-контейнера

position: relative - делает элемент "якорем". Дочерние элементы с absolute будут отсчитывать свои координаты от него.

position: absolute - вырывает элемент из обычного потока и позволяет двигать его по координатам относительно ближайшего "родителя" с relative.

top, left, right, bottom - координаты для сдвига элемента с position: absolute (отступ от соответствующего края родителя).

z-index - порядок наложения элементов по оси Z (кто выше, кто ниже). Чем больше число, тем выше элемент (ближе к пользователю).

margin: 0 auto - центрирует блочный элемент по горизонтали (работает, если у элемента задана ширина)

border - рамка вокруг элемента (пишется как: толщина, стиль, цвет).

border-radius - скругление углов рамки (если написать 50%, прямоугольник превратится в круг или овал).

opacity - прозрачность элемента (от 0 до 1, где 0 - полностью невидимый).

color - цвет текста.

font-size - размер шрифта.

font-weight - жирность шрифта (400 - обычный, 700 и 900 - жирный).

text-transform: uppercase - делает все буквы заглавными.

line-height - высота строки (межстрочный интервал).

text-align - выравнивание текста (left, center, right).

white-space: nowrap - запрещает перенос текста на новую строку (весь текст идет в одну линию).

object-fit: contain - картинка вписывается в заданные размеры, сохраняя свои пропорции (не растягивается и не сжимается).

display: flex - включает гибкую верстку, элементы внутри выстраиваются в ряд по умолчанию.

flex-direction: column - меняет направление flex-элементов с горизонтального на вертикальное (в столбик).

justify-content - выравнивает элементы по главной оси (например, center - по центру, space-between - раскидывает по краям с равными промежутками).

align-items - выравнивает элементы по поперечной оси (например, center - по центру вертикали).

align-items: baseline - выравнивает элементы по базовой линии текста (удобно для букв разного размера).

flex-wrap: wrap - разрешает элементам переноситься на новую строку, если не хватает места

transform - трансформация элемента без изменения общего макета страницы.

rotate() - поворот элемента на заданный угол (например, rotate(45deg)).

translate() - сдвиг элемента по осям X и Y (например, translate(15px, -15px) сдвинет вправо и вверх).

translateX(-50%) - сдвиг элемента только по горизонтали (часто используется вместе с left: 50%, чтобы идеально отцентрировать элемент).

pointer-events: none - делает элемент "прозрачным" для кликов мыши (клики проходят сквозь него на элементы ниже).

pointer-events: auto - возвращает элементу способность реагировать на клики мыши.

calc() - функция для математических вычислений прямо в CSS (например, height: calc(100% - 180px) отнимет 180 пикселей от полной высоты)

sway1, sway2, sway3 - названия анимаций для плавного покачивания овальчиков с навыками.

animation - свойство для применения анимации к элементу (указывает имя, длительность, тип скорости и повтор).

animation-duration - длительность одного цикла анимации (например, 20s - 20 секунд, 15s - 15 секунд).

animation-direction: reverse - запускает анимацию в обратном направлении.

linear - равномерная скорость анимации от начала до конца (без ускорений и замедлений).

ease-in-out - анимация начинается медленно, ускоряется в середине и замедляется в конце (плавный старт и финиш).

infinite - бесконечное повторение анимации

@media (max-width: 768px) - медиа-запрос. Применяет стили, написанные внутри него, только если ширина экрана меньше 768 пикселей (адаптив под телефоны и планшеты).

!important - приоритетное правило. Заставляет браузер применить этот стиль в любом случае, игнорируя все остальные правила, даже если они более специфичные (используется в медиа-запросах, чтобы "перебить" основные стили).
